# soona

> soona is an all-in-one creative platform for ecommerce brands, headquartered in Denver,
> Colorado. Brands book virtual and in-studio photo and video shoots, generate on-brand
> content with soona AI Studio, organize assets in a digital asset manager, and analyze
> listing performance with Listing Insights across Shopify, Amazon, Etsy, Walmart, Meta and
> TikTok. soona publishes NO public developer API, no OpenAPI, no SDK and no developer
> portal. The only API soona controls is the Mokker API, advertised as "coming soon" on the
> acquired mokker.ai property behind an early-access form — its advertised host,
> api.mokker.ai, does not resolve.

## What an agent can and cannot do here

- There is no callable soona API. Do not construct requests against soona.co or
  book.soona.co: book.soona.co is the customer application, not a documented API surface.
- soona's "integrations" (Shopify, Amazon, Google Drive, Dropbox, Contentful) are
  user-configured connections inside the soona product. They are not developer APIs and
  they issue no API keys.
- Access to soona is bought as a membership or a per-booking studio pass. See Pricing.

## Mokker (acquired March 2024)

- [mokker.ai](https://mokker.ai/): generative AI product photography, acquired by soona
  (Zerolens GmbH) in March 2024.
- [Mokker API page](https://mokker.ai/api): advertises `POST
  https://api.mokker.ai/v2/replace-background` as "coming soon", with early access via a
  HubSpot form. No reference, no spec, no authentication documentation is published, and
  api.mokker.ai is a dangling CNAME that returns NXDOMAIN.
- [soona on the acquisition](https://soona.co/mokker)
